================================================================================
PART A: TOOL 1 — SOP AUTO-LOGGING (AUTOMATED FORM FILLER)
================================================================================
Runs completely standalone without heavy AI/OCR dependencies (no EasyOCR or PyTorch).
Fills the "Logging SOP" form in under 0.3 seconds via hotkeys or the floating HUD.

--------------------------------------------------------------------------------
A1. ULTRA-FAST INSTALLATION (~5 SECONDS)
--------------------------------------------------------------------------------
* Step 1: Ensure Python 3.10+ is installed (recommended: Python 3.12 - 3.14).
  (Check the box "Add Python to PATH" during Python installation).

* Step 2: Install dependencies:
  - Option 1 (Recommended): Double-click:
      >>>  Install_AutoLogging.bat  <<<
  - Option 2 (Command line):
      pip install -r auto_logging/requirements.txt

> 💡 PRO TIP: `Run_SOP_Admin.bat` has built-in automatic dependency detection!
> On a brand new machine, simply double-click `Run_SOP_Admin.bat` — it will
> automatically install missing packages in 5 seconds and open the HUD immediately.

--------------------------------------------------------------------------------
A2. DISPLAY CALIBRATION (ONE-TIME SETUP)
--------------------------------------------------------------------------------
Supports multi-display switching (Display 4 Main and Display 3 Secondary).

STEP 1: CALIBRATE THE 6 FORM FIELD CENTERS
* Command for Display 4 (Main Monitor):
    python sop_main.py calibrate --display 4
* Command for Display 3 (Secondary Monitor):
    python sop_main.py calibrate --display 3

Instructions:
1. Open the "Logging SOP" form on the target display.
2. Run the command above -> A transparent overlay will appear.
3. Click the center of each of the 6 fields in sequence:
   - Step 1/6: Center of [Vision Functionality]
   - Step 2/6: Center of [Actions Required]
   - Step 3/6: Center of [Maintenance Issues]
   - Step 4/6: Center of [Resolution]
   - Step 5/6: Center of [Comment]
   - Step 6/6: Center of [SEND] button

STEP 2: CALIBRATE DROPDOWN OPTIONS (WITH THE ALT+TAB PRO-TIP)
* Command for Display 4:
    python sop_main.py calibrate_options --display 4
* Command for Display 3:
    python sop_main.py calibrate_options --display 3

★ ALT+TAB TECHNIQUE FOR 100% ACCURACY WITHOUT MOUSE DRIFT:
1. Click the dropdown on the SOP form so the menu expands.
2. Hover your mouse over the target option row (DO NOT click).
3. Keep your hand steady on the mouse, and press:
      >>>  Alt + Tab  <<<
   to switch focus to the CMD window while keeping the cursor in place.
4. Press ENTER on your keyboard. The coordinate is recorded with pixel precision.
5. Move to the next option -> Alt+Tab to CMD -> Press Enter.
6. Repeat for all 4 dropdowns: Vision Functionality, Actions Required, Maintenance Issues, Resolution.

--------------------------------------------------------------------------------
A3. OPERATING SOP AUTO-LOGGING
--------------------------------------------------------------------------------
* Launch tool: Double-click `Run_SOP_Admin.bat` (or run `python sop_main.py`).

* FLOATING HUD FEATURES:
  1. Display Selector: Click `Display 4` or `Display 3` (or press F6 to cycle).
  2. SOP Type Selector (Dropdown):
     - Select [▼ SUSPECT (6 Cases)]: SUSPECT cases display and stay pinned.
     - Select [▼ CHRF (6 Cases)]: Automatically switches to CHRF cases.
     - Your selection is remembered across sessions in the config file.
  3. [▲ Collapse / ▼ Expand] button: Toggle case list to save screen space.
  4. Profiles: Supports switching between Home and Office monitor profiles.

* UNIVERSAL HOTKEY TABLE:
  (The same familiar keys work for both SUSPECT and CHRF modes!)

================================================================================
PART B: TOOL 2 — TELEOPS AUTO-CLAIM (AUTOMATED BOT PICKER)
================================================================================
Uses screen capture (MSS, OpenCV) and OCR (EasyOCR) to monitor the bot table,
automatically click CLAIM, confirm username, and click Connect.

--------------------------------------------------------------------------------
B1. INSTALLATION
--------------------------------------------------------------------------------
* Option 1 (Recommended): Double-click:
    >>>  Install_AutoClaim.bat  <<<
* Option 2 (Command line):
    pip install -r auto_claim/requirements.txt

(Takes 1-2 minutes to install mss, opencv, easyocr, and rapidfuzz).

--------------------------------------------------------------------------------
B2. CONFIGURING USERNAME & SETTINGS
--------------------------------------------------------------------------------
1. Open `auto_claim/config.json`.
2. Set `"username": "YOUR_USERNAME"` to match your Teleops operator username
   (the exact name that appears in the CLAIM cell upon claiming a bot).
3. Optional settings:
   - `"allowed_teleop_types": ["SUSPECT", "CHRF"]` (Allowed bot types).
   - `"site_blocklist": []` (Site codes to skip, e.g. ["SITE1", "SITE2"]).
4. Save the file.

--------------------------------------------------------------------------------
B3. TABLE CALIBRATION
--------------------------------------------------------------------------------
Run in CMD:
    python main.py calibrate

A semi-transparent overlay appears. Drag-select the areas as instructed:
1. DRAG to select the entire BOT TABLE region.
2. DRAG to select the TELEOP TYPE column (containing SUSPECT / CHRF).
3. DRAG to select the SITE column.
4. DRAG to select the ALARMED FOR column.
5. DRAG to select the CLAIM column (showing "CLAIM" text).
6. DRAG to select the SELECT column (containing the blue Select buttons).
7. CLICK the center of the CONNECT button.
Coordinates are automatically saved to `auto_claim/config.json`.

--------------------------------------------------------------------------------
B4. RUNNING AUTO-CLAIM
--------------------------------------------------------------------------------
* Launch tool: Double-click `Run_AutoClaim_Admin.bat` (or run `python main.py`).
* Press **F8**: Start / Stop scanning for available bots.
* Press **F10**: Pause / Resume scanning.
* Press **F9**: Emergency Stop.
* Press **ESC**: Exit the tool completely.

* SAFE WORKFLOW:
  1. Pressing F8 begins scanning for matching rows with "CLAIM".
  2. Clicks CLAIM -> Waits for your username to appear in the cell.
  3. Clicks SELECT -> Clicks CONNECT.
  4. Once 1 bot is successfully connected -> Tool AUTOMATICALLY STOPS scanning,
     ensuring you never accidentally claim a second bot while operating.
  5. After handling the bot, press F8 again to find the next bot.


================================================================================
PART C: TROUBLESHOOTING
================================================================================

1. Error "No module named pyautogui":
   -> Run `Install_AutoLogging.bat` (takes 5 seconds).

2. Error "Failed to register hotkey":
   -> Another instance of the tool is likely running in another CMD window.
      Close old CMD windows and re-launch via `Run_SOP_Admin.bat` or `Run_AutoClaim_Admin.bat`.

3. Clicks are offset or missing the form/table:
   -> Display layout or resolution changed. Re-calibrate:
      + For SOP: `python sop_main.py calibrate --display <3|4>` and `calibrate_options`.
      + For Auto Claim: `python main.py calibrate`.

4. Slow clicks or responsiveness:
   -> Ensure the tools are running as Administrator (launch via the .bat files).
