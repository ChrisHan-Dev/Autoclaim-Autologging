================================================================================
PHẦN A: HƯỚNG DẪN CÔNG CỤ 1 — SOP AUTO-LOGGING (ĐIỀN FORM TỰ ĐỘNG)
================================================================================
Công cụ này chạy HOÀN TOÀN ĐỘC LẬP, không cần EasyOCR, PyTorch hay OpenCV nặng nề.
Giúp điền form "Logging SOP" chỉ trong 0.3 giây bằng bàn phím hoặc Popup HUD.

--------------------------------------------------------------------------------
A1. CÀI ĐẶT SIÊU TỐC (CHỈ MẤT 5 GIÂY)
--------------------------------------------------------------------------------
* Bước 1: Máy tính cần có sẵn Python 3.10 trở lên (khuyên dùng Python 3.12 - 3.14).
  (Khi cài Python, hãy nhớ tích vào ô [X] "Add Python to PATH").

* Bước 2: Cài đặt thư viện:
  - Cách 1 (Khuyên dùng): Click đúp chuột vào file:
      >>>  Install_AutoLogging.bat  <<<
  - Cách 2 (Gõ lệnh CMD):
      pip install -r auto_logging/requirements.txt

> 💡 MẸO ĐẶC BIỆT: File `Run_SOP_Admin.bat` đã được tích hợp tính năng tự động kiểm tra!
> Nếu máy bạn là máy mới toanh chưa cài gì, chỉ cần click đúp `Run_SOP_Admin.bat`, 
> tool sẽ tự động cài đặt `pyautogui` trong 5 giây rồi mở giao diện ngay lập tức!

--------------------------------------------------------------------------------
A2. HIỆU CHUẨN TOẠ ĐỘ (CALIBRATE) TRÊN MÀN HÌNH CỦA BẠN (CHỈ CẦN LÀM 1 LẦN)
--------------------------------------------------------------------------------
Tool hỗ trợ độc lập cả Màn hình 4 (Main) và Màn hình 3 (Phụ).

BƯỚC 1: CALIBRATE TÂM 6 Ô TRÊN FORM SOP
* Lệnh cho Màn hình 4 (Màn chính):
    python sop_main.py calibrate --display 4
* Lệnh cho Màn hình 3 (Màn phụ):
    python sop_main.py calibrate --display 3

Cách làm:
1. Mở sẵn form "Logging SOP" trên màn hình tương ứng.
2. Gõ lệnh trên -> Một lớp phủ màu xanh trong suốt hiện lên.
3. Click chuột lần lượt vào TÂM của 6 mục:
   - Step 1/6: Tâm ô [Vision Functionality]
   - Step 2/6: Tâm ô [Actions Required]
   - Step 3/6: Tâm ô [Maintenance Issues]
   - Step 4/6: Tâm ô [Resolution]
   - Step 5/6: Tâm ô [Comment]
   - Step 6/6: Tâm nút [SEND]

BƯỚC 2: CALIBRATE CÁC MỤC DROPDOWN OPTIONS (KÈM MẸO VÀNG ALT+TAB)
* Lệnh cho Màn hình 4:
    python sop_main.py calibrate_options --display 4
* Lệnh cho Màn hình 3:
    python sop_main.py calibrate_options --display 3

★ TUYỆT CHIÊU ALT+TAB ĐỂ CHUỘT KHÔNG BỊ DI CHUYỂN / CHÍNH XÁC 100%:
1. Dùng chuột click vào ô dropdown trên form SOP để menu xổ danh sách các mục xuống.
2. RÊ CON TRỎ CHUỘT ĐẶT ĐÚNG LÊN DÒNG MỤC CẦN CHỈ (CHỈ ĐẶT CHUỘT LÊN, TUYỆT ĐỐI KHÔNG CLICK).
3. [MẸO VÀNG]: GIỮ NGUYÊN TAY ĐỂ CHUỘT ĐỨNG IM, BẤM TỔ HỢP PHÍM:
      >>>  Alt + Tab  <<<
   để chuyển vùng chọn về cửa sổ CMD mà chuột vẫn đứng im tại pixel của dòng option!
4. Nhấn phím ENTER trên bàn phím. Toạ độ được ghi nhận chính xác từng pixel.
5. Tiếp tục rê chuột đến mục tiếp theo -> Bấm Alt+Tab về CMD -> Nhấn Enter.
6. Lặp lại cho 4 dropdown: Vision Functionality, Actions Required, Maintenance Issues, Resolution.

--------------------------------------------------------------------------------
A3. VẬN HÀNH VÀ SỬ DỤNG SOP AUTO-LOGGING
--------------------------------------------------------------------------------
* Khởi động tool: Click đúp vào file `Run_SOP_Admin.bat` (hoặc gõ `python sop_main.py`).

* GIAO DIỆN POPUP HUD ĐA NĂNG:
  1. Thanh Màn hình: Bấm chọn `🖥️ MÀN 4` hoặc `🖥️ MÀN 3` (hoặc bấm phím F6 để đổi).
  2. Thanh Loại SOP (Dropdown):
     - Khi chọn [▼ SUSPECT (6 Cases)]: Bảng SUSPECT hiện lên và được lưu giữ nguyên ở đó.
     - Khi chọn [▼ CHRF (6 Cases)]: Bảng SUSPECT tự đóng lại và chuyển sang bảng CHRF.
     - Lựa chọn này được lưu vĩnh viễn trong file config, lần sau mở lên vẫn giữ nguyên.
  3. Nút [▲ Đóng / ▼ Mở]: Thu gọn bảng Case bất cứ lúc nào để màn hình gọn gàng hơn.

* BẢNG PHÍM TẮT DÙNG CHUNG CHO CẢ 2 LOẠI:
  (Bạn vẫn bấm CÙNG MỘT CỤM PHÍM QUEN THUỘC, tool tự điền đúng theo loại đang chọn!)

  ┌──────────────┬─────────────────────────────────────────────────────────────┐
  │  PHÍM TẮT    │ KHI ĐANG Ở [SUSPECT]                                        │
  ├──────────────┼─────────────────────────────────────────────────────────────┤
  │ INSERT       │ Case 1: All cam / Align + Extract / Successful              │
  │ HOME         │ Case 2: No cam / No action forced / Unsuccessful            │
  │ PAGE UP      │ Case 3: All cam / No action forced / Not pickable / Unsucc  │
  │ PAGE DOWN    │ Case 4: All cam / Align + Extract / Damaged case / CHD payl │
  │ END          │ Case 5: All cam / No action forced / No case / Successful   │
  │ DELETE       │ Case 6: All cam / No action forced / Rogue case / CHD payl  │
  ├──────────────┼─────────────────────────────────────────────────────────────┤
  │  PHÍM TẮT    │ KHI CHUYỂN SANG [CHRF] (PHỤC HỒI SẠC)                       │
  ├──────────────┼─────────────────────────────────────────────────────────────┤
  │ INSERT       │ Case 1: All cam / Align + Place / Successful                │
  │ HOME         │ Case 2: All cam / Home actuator / Successful                │
  │ PAGE UP      │ Case 3: All cam / Home actuator + Align + Place / Success   │
  │ PAGE DOWN    │ Case 4: All cam / Home / Axes not resp / CHD (no payl)      │
  │ END          │ Case 5: All cam / Home / Sensor malf / CHD (no payl)        │
  │ DELETE       │ Case 6: All cam / Align + Ext / Damaged / CHD (with payl)   │
  ├──────────────┼─────────────────────────────────────────────────────────────┤
  │ F6           │ Đổi qua lại chế độ MÀN HÌNH 4 (Main) <-> MÀN HÌNH 3 (Phụ)   │
  │ Ctrl + ESC   │ Thoát hoàn toàn tool SOP HUD                                │
  └──────────────┴─────────────────────────────────────────────────────────────┘

* TÍNH NĂNG QUICK CLIPBOARD (CLICK 1 CHẠM COPY TỪ KHOÁ SỰ CỐ):
  Phía dưới HUD có sẵn 8 nút bấm lỗi:
    📦 bh_damage_case_on_payload   (Thùng bị hỏng trên tay gắp)
    📦 bh_rogue_case_on_payload    (Thùng lạ / ko xác định trên tay gắp)
    🧹 bh_debris_on_payload        (Rác / mảnh vụn trên tay gắp)
    🩹 bh_tape_on_actuator         (Băng dính kẹt tay gắp cản trở thao tác)
    📡 bh_coh_fail                 (Cảm biến COH báo kẹt ảo)
    ⚙️ bh_actuator_stuck           (Tay gắp bị kẹt / ko di chuyển hết cữ)
    📐 bh_lift_tilts               (Bàn nâng bị nghiêng / chỉ 1 bên chạy)
    ⚠️ bh_bot_damaged              (Bot bị hư hỏng vật lý / tay gắp cong gãy)
  --> Chỉ cần click chuột vào nút là từ khoá tự chép vào clipboard để dán (Ctrl+V)!


================================================================================
PHẦN B: HƯỚNG DẪN CÔNG CỤ 2 — AUTO CLAIM TELEOPS (TỰ ĐỘNG NHẬN BOT)
================================================================================
Công cụ này dùng nhận diện hình ảnh (OpenCV, MSS) và đọc chữ OCR (EasyOCR) để 
quét bảng danh sách Bot, tự động click nút CLAIM, xác nhận username và kết nối Bot.

--------------------------------------------------------------------------------
B1. CÀI ĐẶT THƯ VIỆN AUTO-CLAIM
--------------------------------------------------------------------------------
* Cách 1 (Khuyên dùng): Click đúp chuột vào file:
    >>>  Install_AutoClaim.bat  <<<
* Cách 2 (Gõ lệnh CMD):
    pip install -r auto_claim/requirements.txt

(Chờ 1-2 phút để máy tải xong các gói mss, opencv, easyocr, rapidfuzz).

--------------------------------------------------------------------------------
B2. CÀI ĐẶT USERNAME VÀ CẤU HÌNH BAN ĐẦU
--------------------------------------------------------------------------------
1. Mở file `auto_claim/config.json` bằng Notepad.
2. Tìm dòng `"username": "YOUR_USERNAME_HERE"`, thay bằng đúng tên tài khoản 
   Teleops của bạn (chính là dòng chữ xuất hiện ở ô CLAIM khi nhận bot thành công).
3. Các tuỳ chọn khác (tuỳ chọn):
   - `"allowed_teleop_types": ["SUSPECT", "CHRF"]` (Các loại bot cho phép nhận).
   - `"site_blocklist": []` (Danh sách mã Site muốn bỏ qua, ví dụ: ["SITE1", "SITE2"]).
4. Nhấn Ctrl + S để lưu lại file `config.json`.

--------------------------------------------------------------------------------
B3. HIỆU CHUẨN VÙNG BẢNG BOT (CALIBRATE)
--------------------------------------------------------------------------------
Gõ lệnh vào CMD:
    python main.py calibrate

Một màn hình bán trong suốt hiện ra. Hãy dùng chuột kéo thả các vùng theo hướng dẫn:
1. KÉO CHUỘT chọn toàn bộ VÙNG BẢNG BOT (toàn bộ khu vực danh sách bot).
2. KÉO CHUỘT chọn cột CLAIM (cột xuất hiện chữ "CLAIM").
3. KÉO CHUỘT chọn cột TELEOP TYPE (chứa chữ SUSPECT / CHRF).
4. KÉO CHUỘT chọn cột SELECT (cột chứa các nút Select màu xanh).
5. CLICK CHUỘT vào tâm của nút CONNECT.
Toạ độ sẽ được lưu tự động vào `auto_claim/config.json`.

--------------------------------------------------------------------------------
B4. VẬN HÀNH AUTO CLAIM
--------------------------------------------------------------------------------
* Khởi động tool: Click đúp vào file `Run_AutoClaim_Admin.bat` (hoặc gõ `python main.py`).
* Bấm phím **F8**: Bắt đầu quét hoặc Tạm dừng quét tìm Bot.
* Bấm phím **F9**: Thoát tool hoàn toàn.

* QUY TRÌNH HOẠT ĐỘNG AN TOÀN TUYỆT ĐỐI:
  1. Khi bấm F8, tool quét liên tục tìm dòng bot hợp lệ có chữ CLAIM.
  2. Click CLAIM -> Đợi tên username của bạn xuất hiện để xác nhận bạn đã claim được.
  3. Click SELECT -> Click CONNECT.
  4. Sau khi kết nối thành công 01 Bot -> Tool TỰ ĐỘNG DỪNG LẠI (chuyển sang PAUSED), 
     đảm bảo không bao giờ nhận nhầm thêm bot thứ hai khi bạn đang điều khiển.
  5. Xử lý bot xong, chỉ cần bấm lại phím F8 để tool tìm bot tiếp theo.


================================================================================
PHẦN C: XỬ LÝ SỰ CỐ THƯỜNG GẶP (TROUBLESHOOTING)
================================================================================

1. Báo lỗi "No module named pyautogui":
   -> Click đúp chạy file `Install_AutoLogging.bat` (mất 5 giây).

2. Báo lỗi "Failed to register hotkey":
   -> Do bạn đang mở nhiều cửa sổ CMD chạy tool cùng một lúc. Hãy đóng hết các cửa 
      sổ CMD cũ rồi mở lại bằng `Run_SOP_Admin.bat` hoặc `Run_AutoClaim_Admin.bat`.

3. Lệch toạ độ khi click vào form SOP hoặc bảng bot:
   -> Do cửa sổ ứng dụng bị di chuyển hoặc đổi độ phân giải.
   -> Chạy lại lệnh calibrate tương ứng:
      + Với SOP: `python sop_main.py calibrate --display <3|4>` và `calibrate_options`.
      + Với Auto Claim: `python main.py calibrate`.

4. Chữ hiển thị hoặc click chậm hơn bình thường:
   -> Đảm bảo đang mở tool dưới quyền Administrator (click đúp qua các file .bat).
